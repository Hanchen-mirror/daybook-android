# 日常账本 1.0.1 使用说明

## 安装与升级

Android 8.0 及以上，建议更新系统 WebView。MuMu 可将 APK 拖入窗口安装；手机可在文件管理器打开 APK 安装。正式版沿用 1.0.0 签名，可以直接覆盖安装，账单保留。升级前建议导出全部 JSON。

## 账本

点击“记支出”或“记收入”，填入正数金额，选择分类、日期和备注，再保存。普通账本入口日期默认设备当天；金额精确到分，最多两位小数。点击账单可编辑或删除，删除需要再次确认。

## 新增月历

底部点击“日历”进入月历账本。

1. 顶部左右箭头切换月份；点击月份可直接选择月份。
2. 每周从周一开始，每格显示当天支出（橙色）、收入（绿色）和笔数。蓝圈标识今天，浅蓝色格标识选中日期。
3. 点击日期，下方显示该日的账单。没有账单的日期仍可选中。
4. 日历页下方的“记支出 / 记收入”自动填写选中日期，适合补记历史账单。
5. 点击“回到今天”，恢复设备当前月份和日期。

格内大额按千 / 万 / 亿简写，完整账单金额精确到分。切换月份时，如果之前选中日期属于别的月份，将选择新月份的 1 日；若新月份是当前月，则选择今天。

## 统计

“月度”显示逐日收支、分类占比和每日汇总；“年度”显示十二个月及全年合计。点击年度月份进入月度；点击月度日期查看当天明细。

结余是所选时间段内收入减去支出，统计按账单日期计算。

## 导出与恢复

“我的 → 导出账单”支持全部账单、所选月份、所选年份。

| 格式 | 用途 | 可恢复 |
|---|---|---|
| JSON | 完整备份、换设备、程序处理 | 是 |
| CSV | Excel / WPS 分析 | 否 |
| HTML | 浏览器阅读或打印报告 | 否 |

导出后在系统文件选择器选择位置并保存。MuMu 可选择其共享文件夹，再从电脑获取文件。

“导入 JSON 备份”校验全部内容后提示合并。相同编号跳过，已有修改不会被旧备份覆盖；已删除但备份中存在的账单会重新加入。单次导入最多 20 MB、50,000 条，仅支持本应用 CNY / schemaVersion 1 格式。

## 保存与备份

账单保存在设备本地 SQLite，应用无需账户或网络。没有自动云同步；卸载或清除应用数据会删除账本，因此请定期导出全部 JSON 并另存到电脑。导出文件是明文，请自行保管。

日期跟随设备本地日期，请正确设置系统时间和时区。当前版本支持单账本、人民币、固定分类、手动记账。
